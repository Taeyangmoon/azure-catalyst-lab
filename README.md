# Azure Catalyst 핸즈온 랩

ServiceNow CMDB 내보내기에서 시작해 Azure Catalyst(구 Azure Migrate)로 현대화 계획을 세우고, 레거시 Java 앱을 Azure Container Apps로 옮겨 보는 실습입니다.

📖 **랩 문서(GitHub Pages)**: https://taeyangmoon.github.io/azure-catalyst-lab/

> 교육용 샘플입니다. Azure Catalyst와 Catalyst 에이전트의 일부 기능은 Preview이며 화면과 동작이 바뀔 수 있습니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `docs/` | 랩 문서(GitHub Pages) |
| `data/` | Contoso Korea CMDB 내보내기(`servicenow_cmdb_export.csv`) |
| `scripts/` | 데이터 생성 스크립트 |
| `apps/legacy-orders/` | 현대화할 레거시 Java(Tomcat) 앱 |
